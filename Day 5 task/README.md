# 🧪 API Test Suite using Postman

## 📌 Project Overview

This repository contains REST API testing documentation created using the **JSONPlaceholder** public REST API. The project demonstrates functional testing, validation testing, response verification, and API documentation using **Postman Web**.

---

## 🎯 Objectives

- Perform REST API Functional Testing
- Validate HTTP Status Codes
- Verify Response Body and Required Fields
- Perform Validation and Negative Testing
- Document API Test Cases and Observations

---

## 🛠 Tools Used

- Postman Web
- JSONPlaceholder REST API
- Microsoft Word
- GitHub

---

## 🌐 API Information

**API Name:** JSONPlaceholder

**Base URL:**
https://jsonplaceholder.typicode.com

**API Type:** REST API

**Response Format:** JSON

## 📝 Notes

JSONPlaceholder is a **mock REST API** created for testing and learning purposes. Some behaviors, such as accepting incomplete data or simulating updates and deletions, are expected characteristics of the mock API. These have been documented as observations rather than software defects.
