# 🚀 Day 4 – SQA Internship | HisabDo

## 📌 REST API Testing using Postman

### 🎯 Objective

The purpose of this task is to practice **REST API Testing** using **Postman** by performing CRUD operations (GET, POST, PUT, PATCH, DELETE), negative testing, documenting test cases, reporting bugs, and capturing test evidence.
